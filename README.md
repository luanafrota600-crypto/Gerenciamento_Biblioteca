# 📚 Sistema de Gerenciamento de Biblioteca

Projeto desenvolvido na disciplina de **Orientação a Objetos**, do curso de Tecnologia em Sistemas para Internet – IFAC.

Aplicação desenvolvida em **Java** para gerenciamento de uma biblioteca, aplicando conceitos de Programação Orientada a Objetos e organização do sistema em camadas/pacotes.

## 💻 Tecnologias e conceitos

- Java
- Programação Orientada a Objetos
- Encapsulamento
- Classes, atributos e métodos
- Construtores e sobrecarga
- Métodos e atributos estáticos
- Collections (`Map`)
- Organização por pacotes
- Modelagem UML

## ⚙️ Funcionalidades

- Cadastro, consulta, listagem e remoção de livros;
- Busca de livros por autor e ISBN;
- Cadastro e gerenciamento de usuários;
- Realização e registro de empréstimos;
- Devolução de livros;
- Controle de exemplares disponíveis;
- Histórico de empréstimos.

## 🏗️ Estrutura

O projeto foi organizado separando responsabilidades em:

- **modelo** — entidades como Livro, Usuário e Empréstimo;
- **repositório** — armazenamento dos dados utilizando `Map`;
- **serviço** — regras de negócio e casos de uso;
- **aplicação** — execução e interação com o usuário.
